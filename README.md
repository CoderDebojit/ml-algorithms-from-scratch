# 📌 Project Overview

This repository contains implementations of fundamental Machine Learning and Neural Network algorithms developed from scratch using Python.

Unlike traditional projects that rely heavily on machine learning frameworks, these implementations focus on the underlying mathematical concepts and algorithmic logic behind model training, prediction, clustering, and learning.

The goal is to gain a deeper understanding of how machine learning algorithms work internally before using high-level libraries.

---

# 🎯 Objectives

This repository was created to:

* Understand machine learning algorithms mathematically
* Implement learning algorithms from first principles
* Explore supervised and unsupervised learning techniques
* Study neural network training mechanisms
* Build strong foundations for advanced AI and Deep Learning

# 🔬 Algorithms Implemented

## 📈 Supervised Learning

### K-Nearest Neighbours (KNN)

* Distance-based classification
* Euclidean distance calculation
* Majority voting mechanism

### Linear Regression

* Least Squares Method
* Regression coefficient estimation
* R² score evaluation

### Logistic Regression

* Binary classification
* Sigmoid activation function
* Gradient descent optimization

### Naïve Bayes

* Probabilistic classifier
* Bayes Theorem implementation
* Conditional probability calculation

---

## 📊 Unsupervised Learning

### K-Means Clustering

* Centroid initialization
* Cluster assignment
* Iterative centroid updates

### K-Medoid Clustering

* Manhattan distance
* Medoid optimization
* Cost minimization approach

### Fuzzy C-Means

* Soft clustering technique
* Membership matrix calculation
* Fuzzy partitioning of data

---

## 🧠 Neural Networks

### Hebb Learning

* Hebbian learning rule
* Weight adaptation through correlation
* Pattern learning demonstration

### ADALINE

* Adaptive Linear Neuron
* LMS (Least Mean Squares) learning
* Continuous activation output

### Backpropagation

* Feed-forward neural network
* Error propagation
* Weight update using gradient descent

# 🚀 How to Run

## Clone Repository

```bash
git clone https://github.com/CoderDebojit/ml-algorithms-from-scratch.git
```

## Navigate to Project

```bash
cd ml-algorithms-from-scratch
```

## Install Dependencies

```bash
pip install -r requirements.txt
```

## Run Any Algorithm

```bash
python supervised/knn.py

python supervised/linear-regression.py

python unsupervised/k-means.py

python neural-networks/backpropagation.py
```
